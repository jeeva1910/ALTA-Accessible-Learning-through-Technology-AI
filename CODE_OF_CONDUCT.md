# Code of Conduct

## Our Commitment

We are committed to making participation in the ALTA project respectful, inclusive and constructive.

## Expected Behavior

Contributors should:
- communicate respectfully
- welcome different perspectives
- focus criticism on ideas and implementation
- respect accessibility needs
- provide useful and constructive feedback
- protect private information and credentials

## Unacceptable Behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, publishing private information, or sharing credentials are not acceptable.

## Enforcement

Project maintainers may remove inappropriate content, reject contributions, or restrict participation when conduct violates this code.

## Reporting

Report conduct concerns privately to the project maintainers rather than escalating them publicly.

This code applies to project spaces and interactions related to ALTA.
